## 🎨 Personnalisation Rapide

### Changer les Couleurs

Dans `styles.css`, lignes 2-18, modifiez :
```css
--primary-color: #0A2463;    /* Bleu principal */
--accent-color: #1E88E5;     /* Bleu accent */
```

### Ajouter un Projet

Copiez-collez un bloc `.project-card` (lignes ~450-470) et modifiez :
- Le titre
- La description
- Les tags
- L'icône

### Modifier les Compétences

Ajustez les pourcentages dans les barres de compétences :
```html
<div class="skill-progress" style="width: 90%"></div>
```

## 🌐 Mettre en Ligne (Gratuit)

### Option 1 : GitHub Pages (Recommandé)

```bash
# Dans le dossier portfolio
git init
git add .
git commit -m "Mon portfolio aéronautique"
git branch -M main
git remote add origin https://github.com/VOTRE-USERNAME/portfolio.git
git push -u origin main
```

Puis activez GitHub Pages dans Settings → Pages

### Option 2 : Netlify (Le Plus Simple)

1. Allez sur netlify.com
2. Glissez-déposez le dossier `portfolio`
3. Votre site est en ligne! 🎉

### Option 3 : Vercel

```bash
npm i -g vercel
cd portfolio
vercel
```

## 🔧 Résolution de Problèmes

### Le portfolio ne s'affiche pas correctement
- Vérifiez que tous les fichiers sont dans le même dossier
- Ouvrez la console du navigateur (F12) pour voir les erreurs

### Les icônes ne s'affichent pas
- Vérifiez votre connexion internet (Font Awesome est chargé en ligne)

### Le changement de langue ne fonctionne pas
- Vérifiez que `script.js` est bien dans le même dossier
- Ouvrez la console (F12) pour voir les erreurs JavaScript
